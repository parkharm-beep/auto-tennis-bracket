# Tennis Input Template

빈 입력 엑셀 템플릿 생성 + 채워진 입력 엑셀 파싱을 담당.

## 입력 엑셀 구조

두 시트로 구성:

### 시트 1: `참가자`
| 컬럼 | 형식 | 예시 | 비고 |
|------|------|------|------|
| 번호 | 정수 | 1 | 자동 부여, 사용자가 안 적어도 됨 |
| 이름 | 문자열 | 김도윤 | 중복 불가 |
| 성별 | "남" 또는 "여" | 남 | |
| 구력 | 정수 (년) | 5 | 0 이상 |
| 구분 | "정회원" 또는 "게스트" | 정회원 | |
| 클럽 | 문자열 | (옵션) | 교류전 때만 입력, 비우면 '우리클럽' |
| IN시간 | HH:MM | 07:00 | 30분 단위 |
| OUT시간 | HH:MM | 12:00 | 30분 단위, IN보다 늦어야 함 |
| 최소게임수 | 정수 | (옵션) | 적으면 그 이상 배정 보장(가용 슬롯 한도), 1 이상 |
| 최대게임수 | 정수 | (옵션) | 적으면 그 이하로만 배정(hard), 1 이상 |
| 혼복희망 | 정수 | (옵션) | 본인 게임 중 혼복으로 뛰고 싶은 게임 수. 비우면 기본(미기재 시 알고리즘 동작은 이전과 완전히 동일) |
| 연속게임 | "금지"/"허용" (옵션) | (옵션) | 연속 출전에 대한 개인별 예외. 빈칸=기본(2연속 OK·3연속 하드 금지, 현행 그대로) / 금지=2연속도 금지(한 게임 뛰면 반드시 한 게임 쉼) / 허용=3연속도 허용(그 사람만 하드 금지 면제 — 짧은 시간에 많은 게임을 보장해야 할 때만). 아무도 안 적으면 알고리즘 동작은 이전과 완전히 동일 |
| 메모 | 문자열 | (옵션) | 자유 기재 |

### 시트 2: `코트`
| 컬럼 | 형식 | 예시 |
|------|------|------|
| 코트명 | 문자열 | A |
| 시작시간 | HH:MM | 07:00 |
| 종료시간 | HH:MM | 12:00 |

기본값으로 A=1번 (07:00-12:00), B=2번 (07:00-12:00), C=3번 (07:00-09:00) 3행을 채워둠(26.8.8~ 운영시간).
사용자가 자유롭게 추가/삭제/수정.

### 시트 3: `씨드대진` (선택)

결과 대진표 엑셀과 **셀 좌표가 1:1로 동일한 그리드**다 — 1열=구분/시간, 2열=성함·결과 라벨,
3열부터 코트당 5열(팀1a·팀1b·VS·팀2a·팀2b), 슬롯당 2행(성함/결과). 지난주 결과 대진표에서
블록을 복사해 그대로 붙여넣을 수 있다.

고정하고 싶은 칸에만 이름을 적는다. **적은 자리(팀·칸 위치)가 그대로 유지된다:**
- 1칸 = 그 사람만 그 자리에 고정
- 같은 편 2칸 = 그 둘이 같은 팀
- 4칸 전부 = 경기 통째 고정

이름은 참가자 시트와 동일 표기(게스트는 `홍길동(G)` 허용). 그 슬롯에 운영하지 않는 코트 칸은
회색으로 비활성 표시. **시트를 비워 두면 기존과 완전히 동일하게 동작**(무변화 회귀 확인됨 —
샘플 3케이스 `02_bracket.json` md5 일치: 21명 시드7 `92612b3d…` / 시드42 `4bc988a9…` /
13명 시드7 `b7e1cb17…`).

### 시트 4: `안내` (읽기 전용, 사용자가 채우지 않음)
- 작성 가이드와 주의사항 텍스트

## 멤버 설정 파일 (클럽멤버_설정.xlsx)

`build_member_settings()`로 생성(CLI `--member-settings` / 웹 '멤버 설정 다운로드'), `parse_member_settings()`로 파싱.
- **멤버 시트**: 번호·카톡아이디·실제이름 (26.8.2 카톡 투표 확정본 25명, `MEMBERS_DEFAULT`)
- **부부 시트**: 이름1·이름2·부부페어(원함/피함 드롭다운)·종료시간차(같이/30분차이 드롭다운)·메모.
  기본값 `COUPLES_DEFAULT` 5쌍 — 신혁재·방미라만 종료시간차=30분차이(반드시 정확히 30분 차이로 종료)
  (박경수·서명숙/신혁재·방미라/원유철·이지은/이선우·김희진 피함, 한병익·전혜선 원함.
   이선우·김희진은 게스트 부부 — 둘 다 참가한 주에만 발동)
- 파싱은 부부 시트만 알고리즘에 전달(`parsed["couples"]`). 이름은 참가자 시트의 실제이름과 일치해야 매칭.
- 우선순위: `--members` 명시 > `입력/클럽멤버_설정.xlsx` 자동 감지 > 내장 기본값 > `--no-members`로 끔

## 주간 초안 생성 (build_draft.py)

카카오 일정 텍스트(참석/불참 목록 + 설명란 게스트) → 입력 엑셀 초안. 오케스트레이터 Phase C가 사용.
```powershell
python build_draft.py --snapshot <일정텍스트.txt> --members 입력/클럽멤버_설정.xlsx `
  [--guest-gender "이름=남|여"] [--guest-max N(기본 0=제약 없음)] [--out 입력/테니스_입력양식.xlsx]
```
- 카톡아이디→실명(이모지·공백 무시), 성별·구력=멤버 설정, IN/OUT·최소/최대=사전채움 승계
- 게스트: 'N년' 또는 등급 호칭(금배=20년·은배=15년·동배=10년, `RANK_EXP`) 구력 파싱, 게임수 제약은 기본 없음(`--guest-max` 명시 시에만), 성별은 옵션으로 지정
- 명단에 없는 참석자는 제외+경고, 기존 출력 파일은 `_백업_YYYYMMDD` 자동 백업

## 검증 규칙 (parse_input.py 자체 수행)

실패 케이스는 stderr에 한국어로 명확히 출력 + exit code 1:
- 필수 컬럼 누락
- 이름 중복
- 시간 형식 오류 (HH:MM 아님, 30분 단위 아님)
- IN ≥ OUT
- 성별이 "남"/"여" 아님
- 구분이 "정회원"/"게스트" 아님
- 최소게임수/최대게임수가 1 미만이거나 정수 아님, 최소게임수 > 최대게임수
- 혼복희망이 정수 아님: `'{이름}': 혼복희망은 정수여야 합니다 (현재: '...')`
- 혼복희망이 1 미만: `'{이름}': 혼복희망은 1 이상이어야 합니다`
- 혼복희망 > 최대게임수: `'{이름}': 혼복희망(N)이 최대게임수(M)보다 큽니다`
- 연속게임이 '금지'/'허용' 동의어(공백 제거 후 비교: 금지=금지/연속금지/불가/안함, 허용=허용/연속허용/가능/연속게임가능) 외의 값: `'{이름}': 연속게임은 '금지' 또는 '허용'만 입력하세요 (현재: '...')`
- 코트의 시작 ≥ 종료
- 참가자 < 4명

혼복희망 클램프는 `parse_input.clamp_mixed_wish()` 공용 함수가 수행하며, **CLI(`parse_input.main`)와 웹(`web/py/run.py`) 둘 다** 이 함수를 호출한다(한쪽만 걸면 웹이 무방비가 된다).

경고 케이스는 stderr에 "[경고]" 접두로 출력 + 정상 진행:
- 남자(여자) 4명 미만 → 단성 복식 불가 안내
- 특정 시간대 가용 인원 4명 미만
- 코트 운영 시간이 모든 참가자 IN 범위 밖
- 최소게임수 > 본인 가용 슬롯수 (가용 슬롯 수까지만 보장 — 연속게임 설정을 반영한 한도. 금지=인접 슬롯 동시 배정 제외, 허용=슬롯 수 그대로, 빈칸=3연속 금지 하 최대. 문구도 모드에 맞게 갈림: 빈칸 "3연속 없이 가능한 최대(N게임)" / 금지 "연속금지 하에 가능한 최대(N게임)" / 허용은 슬롯 수 그대로이므로 이 경고 자체가 잘 안 뜸)
- 최소게임수 합계 > 전체 배정 가능 자리 (일부 보장 불가 가능)
- 혼복희망 > 본인이 실제로 뛸 수 있는 최대 게임수(= `_max_games_streak(가용 슬롯, 본인 연속게임)`, 구 `_max_games_no3`를 연속게임 모드까지 일반화한 것, 최대게임수가 있으면 그것과의 min):
  `'{이름}': 혼복희망(N) > 본인이 뛸 수 있는 최대(C게임) — C게임까지만 반영됨` (경고 후 그 값으로 자동 클램프)

## 씨드대진 검증 규칙 (parse_input.parse_seed())

`씨드대진` 시트가 비어 있으면 이 절 전체가 동작하지 않는다(기존과 완전히 동일). 채워졌을 때만:

실패 케이스(stderr 출력 + 생성 중단):
- 참가자 시트에 없는 이름
- 같은 사람이 같은 슬롯에 두 번 등장 (다른 코트 포함)
- 그 시간에 운영하지 않는 코트에 배정
- 그 사람의 IN~OUT 범위 밖 슬롯
- 시각을 인식할 수 없음 / 코트 시간표에 없는 시각
- 헤더 손상 (그리드 좌표가 결과 양식과 안 맞음)
- 그 경기의 성별 조합으로는 남복·여복·혼복 어느 것으로도 완성할 수 없음
  (남복=전원 남, 여복=전원 여, 혼복=각 팀 남1+여1 중 어느 것도 성립 안 함)
- **VS칸 침범** (2차 독립 리뷰 검출) — 성함 행의 가운데(VS) 칸이 `VS`/`혼`/빈칸이 아니면
  열이 한 칸 어긋난 붙여넣기로 보고 에러. 그냥 두면 그 자리에 있어야 할 사람은 조용히
  사라지고 나머지는 옆자리로 밀려 **다른 대진이 확정된다** — 실패가 아니라 틀린 성공이라
  더 위험하다
- **인식되지 않는 위치의 이름** (2차 독립 리뷰 검출) — 격자 안(코트 열 범위)에서
  '성함 행 × 좌석 열'이 아닌 칸에 참가자 이름이 있으면 에러. '결과' 행에 붙여넣거나 중간
  시간 라벨이 지워져 그 아래가 통째로 무시되는 경우를 잡는다(둘 다 종전엔 완전 무음이었고,
  웹은 씨드 표시 자체가 없어 사용자가 알 길이 없었다)
- **슬롯 단위 인원 합계** (2차 독립 리뷰 검출) — 같은 시각의 고정들을 **합쳐서** 검사한다.
  종류가 아직 안 정해진 고정(혼복인지 단성 복식인지 미확정)은 '가장 적게 쓰는 종류' 기준으로
  세어 확실한 하한을 만들고, `필요 최소 남/여 > 그 시각 가용 남/여`면 에러. 예: 여자 5명인
  슬롯에 A코트 여복 4명 + B코트 혼복 1자리를 동시에 고정하면 여자만 6명이 필요해져
  **시드를 바꿔도 절대 채울 수 없다**(경기 하나씩 보면 통과하지만 합쳐 보면 모자라는 경우).
  기존의 pin 하나짜리 인원 검사(위 항목)는 그대로 두고 이 슬롯 합산 검사가 추가된 것

경고 케이스("[경고]" 접두 + 정상 진행):
- 남녀가 섞여 있어 자동으로 혼복이 됨
- 씨드만으로 이미 그 사람의 최대게임수를 넘김
- 씨드만으로 이미 그 사람의 연속게임 한도(빈칸/금지/허용)를 넘김

CLI(`parse_input.main`)와 웹(`web/py/run.py`) **양쪽 모두** `parse_seed()`를 호출한다
(혼복희망 클램프와 같은 원칙 — 한쪽만 걸면 사용자가 상시 쓰는 웹이 무방비가 된다).

**주의**: 씨드 격자는 항상 `COURTS_DEFAULT`(A·B 07:00~12:00, C 07:00~09:00) 기준으로 생성된다.
'코트' 시트를 편집해 운영시간을 바꾸면 씨드대진 시트의 회색(비활성)/노란색 표시가 실제와
달라질 수 있다 — **판정 기준은 언제나 '코트' 시트**이고, 씨드대진 시트 1행 안내에도 그
취지("이 격자는 '코트' 시트 기본값 기준입니다 … 판정은 '코트' 시트가 기준입니다")를 적어 두었다.

## 셀 서식 (build_template.py 산출)
- 헤더 행: 굵게 + 회색 배경 + 가운데 정렬
- 데이터 셀: 가운데 정렬
- 시간 컬럼: 텍스트 형식 (HH:MM 그대로 입력받기 위해)
- 컬럼 너비: 자동 조정
- `안내` 시트에 워크플로우 설명 + 예시
