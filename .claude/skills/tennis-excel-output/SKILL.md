# Tennis Excel Output

`_workspace/01_parsed.json` + `_workspace/02_bracket.json`을 읽어 첨부 이미지 양식의 결과 엑셀을 생성.

## 출력 양식 (첨부 이미지 기반)

```
+---------+--------+--------+--------+--------+--------+--------+--------+----+------+----+
|         | 1번코트          | 2번코트          | 3번코트          |    참가자  게임수  |
+---------+--------+--------+--------+--------+--------+--------+--------+----+------+----+
| 1번게임 | 성함   | t1a t1b VS t2a t2b | ...     | ...     | 1 | 이름 | N |
| 07:00   |--------+--------+--------+--------+--------+--------+--------+    | (IN~OUT)|
| ~07:30  | 결과   |        |        |        |        |        |        |    |       |
+---------+--------+--------+--------+--------+--------+--------+--------+----+-------+
```

- 코트별로 다른 채움색 (예: 코트1=노랑 #FFFF99, 코트2=주황 #FFCC99, 코트3=하늘 #99CCFF)
- 매치 유형 표시: 혼복은 셀에 "혼" 표시 추가 (옵션)
- 게스트는 이름 뒤 "(G)" 표기
- 비어있는 슬롯(공석)은 회색 채움
- 우측 참가자 패널: 좌/우 두 그룹, 한 그룹당 10명 (총 20명까지). 그 이상이면 자동으로 확장.
- 참가자 셀 아래에 "IN시간~OUT시간" 작은 글씨 + 최소/최대게임수 지정 시 "최소 N게임/최대 N게임" 표기

## '통계' 시트 (두 번째 시트) — 전부 엑셀 수식(손 수정 시 자동 재계산)

**사람별 통계 테이블** (`_build_stats_sheet` + 숨김 시트 `통계_계산`을 만드는 `_build_calc_sheet`):
- 번호 · 이름((G) 표기·이탤릭) · (교류전이면 클럽) · 성별 · 구력 · 참석(IN~OUT) — 정적(입력값)
- 게임수 · 남복/여복/혼복 게임수 — 수식. **혼복 판정은 팀 사이 칸의 "혼" 표기 기준**(SUMPRODUCT),
  남복/여복은 본인 성별로 분류(단성 복식 = 본인 성별 게임)
- 첫 경기 · 마지막 경기(종료 시각) · 첫 대기(분, 실질 도착(`eff_in`) 기준·음수는 0 클램프) — 수식
- **최대 연속 게임** · **최대 연속 휴식(분)** · **1시간+ 공백(회)** · 총 대기(분) — 수식
- 파트너 수(서로 다른 팀 동료) · 같은 짝 반복(회) — 수식(SUMPRODUCT 고유값 카운트)
- 빨간 강조(휴식 60분+ / 1시간+ 공백 발생)는 **조건부 서식**(값이 수식이라 정적 폰트로는 불가)
- 정렬은 명단 패널과 동일(가용 슬롯 많은 순, 교류전은 클럽별 묶음), 헤더 행 고정(freeze)

**숨김 시트 `통계_계산`** (사람=행, 슬롯=열 매트릭스 5블록 + 첫슬롯/종료 분):
P=출전 0/1(대진표 '성함' 행 COUNTIF) → S=연속게임 run → R=휴식연속(첫 경기 전 0 게이트)
→ G=경기 직전 공백 슬롯수 → T=파트너 이름(팀 2칸 중 자기 아닌 쪽, 중첩 IF).
고전 함수만 사용(COUNTIF/SUMPRODUCT/LOOKUP/INDEX/MATCH) — 구버전 엑셀에서도 동작, CSE 불필요.

**전체 요약 블록** (테이블 아래, 역시 수식): 총 매치 수(남/여/혼, =Σ게임수/4), 참가자 수(정적),
게임수 평균/최대/최소, 1시간 이상 공백(건수/인원), 총 대기시간 합계, 마지막 경기 종료, (교류전) 클럽별 인원

**한계**: 이름은 대진표 **'성함' 행**에 적어야 집계됨(결과 행은 무시). 손으로 혼복을 만들면
가운데 칸을 "혼"으로 바꿔야 남/여/혼 분류가 맞음. 이름 표기는 명단과 정확히 일치해야 함(게스트는 "이름(G)").

## 사용

```powershell
python C:\Works\auto-tennis-bracket\.claude\skills\tennis-excel-output\scripts\render_bracket.py `
  --parsed  C:\Works\auto-tennis-bracket\_workspace\01_parsed.json `
  --bracket C:\Works\auto-tennis-bracket\_workspace\02_bracket.json `
  --out     C:\Works\auto-tennis-bracket\테니스_대진표_20260530.xlsx `
  --date    "26.5.30" `
  --title   "우리 테니스 클럽 이번 주 대진표"
```

## 셀 서식 규칙
- 폰트: 맑은 고딕 11pt, 이름은 굵게 10pt
- 시간/번호 셀: 가운데 정렬
- 이름 셀: 가운데 정렬, 코트색 배경
- "VS" 셀: 회색 가는 배경
- 결과 행은 흰색(비어있음)
- 외곽선: 모든 셀에 얇은 검정 테두리
- 컬럼 너비: 시간 7, 성함/결과 8, 이름 칸 10
- 행 높이: 성함/결과 각 22
